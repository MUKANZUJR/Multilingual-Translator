# Multilingual-Translator
LinguaFlow is a modern, lightweight, and user-friendly multilingual translation web application built with vanilla HTML, CSS, and JavaScript. It provides fast translations, automatic language detection, text-to-speech, clipboard copying, and a polished light/dark mode UI—all without frameworks.

✨ Features

🌐 Multilingual Translation (15+ languages)

🤖 Automatic Language Detection

🌗 Light & Dark Mode (saved in localStorage)

🔊 Text-to-Speech using Web Speech API

📋 Copy to Clipboard (input & output)

🔁 One-click Language Switch

⚡ Debounced API Requests for performance

🚦 Character Counter (500 max)

🧠 Graceful Error Handling

📱 Fully Responsive Design

🎨 Modern UI with Animations & Toast Notifications

🖥️ Tech Stack

HTML5 – Structure & accessibility

CSS3 – Custom properties, animations, dark mode

JavaScript (ES6+) – App logic & API handling

Web Speech API – Text-to-speech

MyMemory Translated API – Free translation service

🔧 How It Works

User inputs text (max 500 characters)

Translation requests are debounced (800ms)

API returns translated text

Output supports:

🔊 Speech playback

📋 Copy to clipboard

Theme preference is saved automatically

🌗 Dark Mode Support

Toggle button in the header

Theme state stored in localStorage

Automatically applied on page reload

🧪 Supported Languages

English, French, Spanish, German, Italian, Portuguese, Dutch, Russian, Chinese, Japanese, Arabic, Korean, Polish, Swedish, Turkish

⚠️ Limitations

Translation accuracy depends on the public API

Requires an internet connection

Text-to-speech support varies by browser
